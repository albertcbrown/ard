### Risk

Medium. It changes the shared pipeline used by every scanner (create labels, join check, new early return), so a mistake affects `cve` filing. No migration and no new run outcome, no change to protected paths (`.ard/config.yaml`, `.ard/scanners/` untouched; docs and Go only; `docs/proposal.md` is not protected). `joinableIssue` and `Role` are internal interfaces. The guard handles secret material: it must never log or return the matched text. The gitleaks pass runs a subprocess per field if scanned naively; mitigate by scanning one joined, newline-separated buffer per finding and mapping line numbers back to fields, or by accepting per-field runs (slow) — decide in the worker; prefer the single-buffer approach.
