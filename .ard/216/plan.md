Body must keep keywords such as token/secret/password out of positions before `:` or `=`.

New `internal/roles/scanners/trufflehog/scan` (mode 0755, POSIX sh): `set -eu`; find siblings from `$0`; exit 2 if `trufflehog`, `jq` or both `sha256sum` and `shasum` are missing; `mktemp -d` with an EXIT trap; always exclude `^\.git(/|$)` plus `exclude-paths`; validate the optional `allow` file (`trufflehog:<16 hex>`, `#` comments), failing on a bad entry; run `trufflehog filesystem . --json --no-update --no-color --no-verification --no-ignore-tag --fail-on-scan-errors --concurrency=2 -x <file>`, piping through jq project (stderr to /dev/null) and a hash loop with preimage `ard-trufflehog-v1` NUL base64(secret), 16 hex chars; record every stage's exit status in files; fail closed on non-zero status, missing `finished scanning` summary, zero chunks on a non-empty tree, or result count differing from verified+unverified; print stdout only last. Never `set -x`; never use the forbidden flags (`--since-commit`, `--max-depth`, `--detector-timeout`, `--archive-timeout`, `--filter-unverified`, `--filter-entropy`, `--results`). Use `tab=$(printf '\t')`.

### Test plan

Command: `go test ./internal/roles/... ./internal/initcmd/... ./internal/config/...`, then `go vet ./...`. No network and no real trufflehog; a fake `trufflehog` sh script records argv and the `-x` file, and replays stdout, stderr and exit code from env-pointed files. Hermetic PATH of symlinked tools.
- `TestTrufflehogFingerprintGolden`: `canary-raw-alpha` gives `trufflehog:d4bf4d1967fad7b7`, `canary-raw-beta` gives `trufflehog:ce658c895bb3b307`, also recomputed in Go; stable across detector, location, differing `RawV2`; empty `Raw` falls back to `RawV2`. Verify these golden values by running the script; if they differ, the script is wrong, not the golden.
- `TestTrufflehogAggregates`: alpha by two detectors in two files (one duplicate location) plus beta; compare to `aggregate.want.jsonl`; 2 findings, files `["a.txt","sub/b.txt"]`, lowest detector title, severity `high`, group `""`.
- `TestTrufflehogDeterministic`: reversed and rotated input and a second run give byte-identical stdout.
- `TestTrufflehogOutputPassesGuards`: `scanner.DecodeFindings` accepts output; `redact.Builtin()` finds nothing in title, body, fingerprint, files; 60 locations gives 50 listed plus "and 10 more"; backtick in path gets a longer fence.
- `TestTrufflehogCanary`: unique markers in `Raw`-adjacent fields (`RawV2`, `Redacted`, `SecretParts`, `ExtraData`, `StructuredData`, `VerificationError`, `email`, `repository`, `repository_local_path`, `DetectorDescription`) appear nowhere in stdout, stderr or the temp dir; `complete` and `killed` (SIGKILL of the process group mid-stream) subtests.
- `TestTrufflehogFailsClosed` (table): trufflehog exit 1 and 2, no summary, zero chunks on a non-empty repo, count mismatch, malformed line, non-object, absolute path, `..` path, `a/../b`, control character, `Data.Git` source, no Raw/RawV2, bad detector name, bad `allow` entry. Each: non-zero exit, empty stdout, expected stderr text, no canary in stderr, empty temp dir. Positive companions: empty repo with `chunks:0` gives empty stdout; `./a.txt` normalizes to `a.txt`.
- `TestTrufflehogArgv`: exact recorded argv, none of the forbidden flags (also `--include-detectors`, `--exclude-detectors`, `--json-legacy`).
- `TestTrufflehogExcludePaths`: shipped file gives `.git` plus three regexes; removing the file leaves `.git` only.
- `TestTrufflehogAllow`: allowed fingerprint dropped with comments and blanks tolerated; missing `allow` keeps both; count check still passes.
- `TestTrufflehogMissingTool`: no trufflehog, no jq, no hasher: exit 2, empty stdout, `<tool> not found`.
- `TestTrufflehogBodyRunbook`: body has `Do not add` + `ard:pending` sentence and all six runbook steps.
- `TestTrufflehogDockerfilePins`: `ENV TMPDIR=/var/tmp`, `GO_IMAGE` equals cve's, trufflehog version arg, 64-hex checksums, `sha256sum -c`, no COPY of scan files.

### Risk

High-leaning medium. The code handles live secrets: a projection bug would publish a credential in a public issue, so a human must read `scan` and `findings.jq` line by line. Protected path touched: `CLAUDE.md` (merge waits for a human). Public interface: starter config and `ard init` PR body change for every adopter. Security-sensitive: secret only in pipes, never in argv, files, stdout or stderr. AGPL-3.0: nothing may be added to the root `Dockerfile` or the published image. Concurrency: kill and trap handling of the temp dir. Trufflehog checksums cannot be verified offline.
