## Implementation

Context: #407 (the design) is not readable from this checkout; the steps below follow the issue slice and the existing `internal/snapshot` API (`Snapshot`, `Taker.Take`, `Event`, `Ring`). The worker should read #407's "Panels" and "Safety" sections for exact panel wording and key lists before step 5.

### Steps

1. `go.mod` / `go.sum` (new deps): `go get charm.land/bubbletea/v2@v2.1.1 charm.land/lipgloss/v2@v2.1.0` (or later releases at least two weeks old on the PR date; verify the `module` line in each tag's `go.mod` says `charm.land/...`). Keep `CGO_ENABLED=0` (Makefile `build` already sets it); confirm `CGO_ENABLED=0 go build ./...` passes and `go mod tidy` leaves no CGO-only deps. This is the only step that touches go.sum; do it together with step 5's first import so `go mod tidy` does not drop the modules.
2. `internal/cli/app.go`: add `UI string` (or `UIMode` with values auto/on/off) to `ServeOpts`. `internal/cli/cmd_serve.go`: add mutually exclusive `--ui` and `--no-ui` bool flags (use cobra `MarkFlagsMutuallyExclusive`); both set is a usage error (exit 2) like the existing `--loops` errors. Add a case to `internal/cli/cli_test.go`.
3. New `internal/servecmd/tty.go`: `func uiWanted(mode uiMode, stdin, stdout any, getenv func(string) string) bool`. True only when mode is not off, `TERM` is not `dumb`/empty, and both stdin and stdout are `*os.File` terminals. Use `golang.org/x/sys/unix`/`term`-free detection: `github.com/mattn/go-isatty` is already an indirect dep (promote to direct), or `os.File.Stat().Mode()&os.ModeCharDevice` plus isatty. `--ui` forces on but still refuses with a clear error when not a TTY. Env.Stdout/Stderr are `io.Writer`, so type-assert `*os.File`; anything else means no UI.
4. New `internal/servecmd/uilog.go`: `openServeLog(home string, r github.Repo) (*capFile, string, error)` creating `~/.ard/logs/<owner>/<repo>/serve.log` via `repopath.Join`, dir 0700, file 0600 (`os.OpenFile` with `O_APPEND|O_CREATE`, then `Chmod`). `capFile` is an `io.Writer` with a size cap (for example 10 MiB): on reaching the cap, rotate to `serve.log.1` (replace, 0600) and reopen; mutex-guarded. In `serveLoops` (`internal/servecmd/serve.go`, near line 188 where `log` is built) when the UI will run, build the base handler as `slog.NewTextHandler(capFile, ...)` with the level from `e.Log` (use `e.Log.Handler().Enabled` is not enough to rebuild; simplest is to add `Level` to `cli.Env` or rebuild via `cli.NewLogger(e.Globals.LogLevel, capFile)`) and pass that to `snapshot.NewTee`. Also point `cfgLoader.stderr` (line 252) and any child-process stderr at the file while the UI runs; grep `Stderr` under `internal/servecmd` and `internal/executor/local` (`proc_unix.go:128`) and pass `capFile` where `e.Stderr` flows. Print the path to the real stderr after the UI exits.
5. New package `internal/ui` (new): 
   - `sanitize.go`: `func Clean(s string) string` strips C0/C1 controls (incl. ESC, CSI/OSC sequences by dropping the whole sequence, DEL), newlines and tabs to a space, invalid UTF-8, and bidi override runes; also `Trunc(s, width)` using display width. Apply to every string from the snapshot (event `Msg`/`Attrs`, `Role`, `Stage`, `Err`, `Errors`, `PauseView.Err`, `Family`, `Window`).
   - `model.go`: Bubble Tea v2 `Model` implementing `Init/Update/View` per the v2 API (check the tag's docs; `View` returns `tea.View` in v2). State: `snap snapshot.Snapshot`, `width,height`, `selected`, `page`, `help bool`, `confirmQuit bool`, `loc` (stderr path), `repo`. Messages: `tickMsg` (1 s `tea.Tick`) triggers `take func(context.Context) snapshot.Snapshot` and returns `snapMsg`; `tea.WindowSizeMsg` updates size. `take` is `w.snap.Take`, which makes no GitHub calls (see `internal/servecmd/snapshot.go`).
   - `view.go`: pure `func Render(m Model) string` using lipgloss v2 styles; panels: header (repo, time, pool used/max, log path), needs you (pauses, capped roles, errors, limits blocks), running, waiting per role, limits, issues (paged by available height), and when height >= ~40 and width >= ~100 add recent events and next tick per loop (from `Snapshot.Events`, `Snapshot.Ticks`). Footer shows `? help  j/k select  o open  q quit`. Never print tokens, env or host paths other than the log path. Make output deterministic (no `time.Now` inside Render; use `snap.TakenAt`).
   - `keys.go`: `?` toggles help; `j`/`down`, `k`/`up` move selection (clamped, page follows); `o` runs an `open func(url string) error` for `https://github.com/<owner>/<repo>/issues/<n>` (inject for tests; build the URL from the integer only; default via `exec.Command("open"|"xdg-open")` with no shell, ignoring errors); `q` sets `confirmQuit`, then `y`/`enter` quits and anything else cancels; `ctrl+c` quits at once and cancels the serve context.
6. New `internal/servecmd/ui.go`: `runWithUI(ctx, w, cc, ...)`. In `serveLoops` replace the final `return cc.Run(ctx)` (serve.go:~368) with: if UI wanted, run `cc.Run(ctx)` in a goroutine under a cancelable child context and run `tea.NewProgram(model, tea.WithInput(os.Stdin), tea.WithOutput(os.Stdout))`; Ctrl-C arrives as a key message in raw mode, and a real SIGINT/SIGTERM still cancels `ctx` (cli.Run's NotifyContext), which sends `tea.Quit` via `p.Send`. On UI exit cancel the controller context and wait for `cc.Run` to return, so shutdown is graceful (same path as today, keep `forceOnSecondSignal`). Return the controller's error. Restore the terminal on every path (`defer`) and print `logs: <path>` after. Without UI, behaviour is byte-for-byte unchanged.
7. `docs/proposal.md`: add a "Command center" paragraph at the end of the **Observability** bullet (line ~543) covering TTY auto-detection, `--ui`/`--no-ui`, the log file path and cap, read-only panels fed by the Snapshot with no GitHub calls, keys, and sanitisation. Check `make docs-check` (internal/docscheck) if it lints the proposal.

### Risk

Medium. New third-party UI dependencies (supply chain, owner decided; verify module paths and pins; CGO stays off), changes to the `ard serve` startup and shutdown path (concurrency between the Bubble Tea program and `cc.Run`, terminal restore, signal handling), log redirection touching how stderr flows to children, and untrusted text drawn to a terminal (escape injection, handled by `Clean`). No migrations. No protected paths in `merge.protected_paths` are touched (`docs/proposal.md`, `go.mod`, `internal/**` only); do not edit `.ard/` or `.github/`. `ServeOpts` and flags are a public CLI interface (additive).
