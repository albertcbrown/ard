### Risk
Medium. The retry loop in `lane.run` is shared by every commit lane and handles the case where a push may have landed, so a mistake could write a duplicate or lose a commit. Security-sensitive: error text goes to logs, so the existing scrubbing must stay in place. It adds a close-out cause and changes how a commit failure maps to a plan, which the Reaper sees. No protected paths in `merge.protected_paths` are touched. No public CLI or migration changes. Concurrency: the lane semaphore is held during backoff (up to about 1 minute), which delays other requests on the same branch.
