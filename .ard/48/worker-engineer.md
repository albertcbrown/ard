Adds a starter lint scanner role (golangci-lint per Go module plus `//nolint` directives, minus a human-owned baseline) so repos can file lint findings beyond a committed baseline. It fails closed on anything that would make findings vanish and autoclose.

## Changes
- `internal/roles/scanners/lint/`: `scan` (POSIX sh, 0755, forced golangci-lint flags, `--baseline` mode, exit codes 0/1/2), `normalize.jq` (fingerprints, collapse, severity, fenced untrusted text, baseline parsing, three modes) and a pinned `Dockerfile`.
- `internal/roles/testdata/lint/`: 15 synthetic cases, 3 real cases (`basic`, `nested_module`, `repo_config_new_only`) and `regen.sh`.
- `internal/roles/lint_test.go`, `lint_scan_test.go`: golden, case-list, decode and untrusted-text tests, and a stubbed end-to-end scan test (argv, exit codes, read-only repo).
- `lint_integration_test.go`, `lint_docker_integration_test.go` (tag `integration`); `scanRunArgs` doc comment generalised.
- `config.yaml`: `scanners/lint` override and four `**/.golangci.*` protected paths. `roles.go` embeds `scanners/lint`.
- `initcmd/body.go`: baseline bullet in the init PR body. Tests updated in `roles_test.go` and `initcmd_test.go`.
- `Makefile`: `lint-scanner-fixtures`. Docs: `docs/proposal.md` (table, "The lint scanner", init and protected-path text) and `docs/layout.md`.

## Testing
- `go test ./...`: all pass. `go vet ./...` and `go vet -tags integration ./internal/roles/`: clean. Changed Go files are gofmt-clean.
- `go test -tags integration -run TestIntegrationLintHost ./internal/roles/` passes with the host's golangci-lint 2.15.0.
- The three real fixture cases were generated by running `regen.sh` with the host's golangci-lint 2.15.0, not hand-built.
