### Test plan
- `TestTrufflehogReal` and `TestTrufflehogDocker` as above, in the two new files. Run by hand: `ARD_TRUFFLEHOG_BIN=<path> go test -tags integration -run Trufflehog ./internal/roles/` (Docker, network and the pinned binary needed). They are not run by `make test`.
- Failure cases: `ARD_TRUFFLEHOG_BIN` at another version must fail, not skip; unset skips the host test only.
- Edge cases: `Raw` over 57 bytes (base64 line wrapping), ignore tag, excluded path, dangling or followed symlink, read-only tree.
- Gate: `make lint test` (compiles nothing with the integration tag, so also run `go vet -tags integration ./internal/roles/`).
